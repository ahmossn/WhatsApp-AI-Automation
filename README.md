# WhatsApp-AI-Automation
# نظام أتمتة واتساب بالذكاء الاصطناعي (WhatsApp AI Automation) 🤖💬

نظام أتمتة ذكي لخدمة العملاء عبر الواتساب يعتمد على **Gemini-2.5-Flash** لتحليل رسائل العملاء، والرد عليها تلقائياً بشكل طبيعي، وتصنيف نية العميل (Intent) ومدى جديته في الشراء.

## 🛑 المشكلة
تواجه الشركات الصغيرة مشكلة تشتت الموظفين وعدم القدرة على الرد الفوري على مئات رسائل الواتساب طوال الـ 24 ساعة، مما يؤدي لخسارة عملاء محتملين.

## ✨ الحل
هذا المشروع يوفر خادم ويب (Webhook) يستقبل رسائل الواتساب، ويمررها لنموذج الذكاء الاصطناعي لتوليد رد مخصص وودي فوراً، مع استخراج بيانات تسويقية هامة مثل (نوع الاستفسار، وجدية العميل) بصيغة JSON مهيكلة.

## 🚀 طريقة التشغيل

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. إعداد مفتاح الـ API
قم بإنشاء ملف `.env` وضَع فيه مفتاح Gemini الخاص بك:
```env
GEMINI_API_KEY="your_gemini_api_key_here"
```

### 3. تشغيل المشروع محلياً
```bash
python app.py
```

### 4. الربط مع واتساب (للإصدار التجريبي)
1. قم بتحميل أداة **ngrok** لفتح السيرفر المحلي للإنترنت: `ngrok http 5000`
2. انسخ الرابط الذي توفره ngrok (ينتهي بـ `.ngrok-free.app`).
3. ضعه داخل إعدادات Webhook في حساب **Twilio Sandbox for WhatsApp**.
